# git_assignment_HeroVired

A small practice repository for basic Python calculators (arithmetic and geometry) used for Git & GitHub learning exercises.

## Contents

- `CalculatorPlus.py` - simple arithmetic utilities (add, subtract, multiply, divide, square root). The file contains a `Calculator` class and example usage in the `__main__` section.
- `GeometryCalculator.py` - geometry helper functions to calculate areas (circle, rectangle). Includes example usage in the `__main__` section.
- `README.md` - this file.

## Requirements

- Python 3.8+ (recommended). No external packages required.

## Usage

Run the example scripts from the repository root. In PowerShell:

```powershell
python .\CalculatorPlus.py
python .\GeometryCalculator.py
```

If you prefer, run them with an explicit Python path (e.g., `python3` on some systems):

```powershell
python3 .\CalculatorPlus.py
python3 .\GeometryCalculator.py
```

Example (intended) output for `CalculatorPlus.py`:

```
16 + 4 = 20
16 - 4 = 12
16 * 4 = 64
16 / 4 = 4.0
The square root of 25 = 5.0
```

Example (intended) output for `GeometryCalculator.py`:

```
The area of the circle with radius 5 = 78.53981633974483
# The rectangle example is currently commented out in the script.
```

## Notes and known issues

- The code files include TODOs and a few incomplete or mis-indented functions. If a script raises an error when you run it, check for TODO comments inside the file and correct the function definitions (for example, ensure methods belong to a class when intended and import required modules such as `math`).
- This repository is used for instructional purposes; feel free to refactor the scripts into well-structured modules or add unit tests.
